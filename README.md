# Void Pointer with Different Data Types

## Author
M.Likitha

## Description
This program demonstrates how a void pointer can store
the address of different data types.

A void pointer does not have a specific data type.
Therefore, it must be type-cast before dereferencing.

## Concepts Used
- Void pointer
- Pointer assignment
- Type casting
- Dereferencing
- int, float, and char data types

## How to Run

Compile:
gcc void_pointer.c -o void_pointer

Run:
./void_pointer

## Sample Output

Integer value: 25
Float value: 45.50
Character value: A
